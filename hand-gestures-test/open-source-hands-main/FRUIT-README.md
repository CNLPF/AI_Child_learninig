# 流光果园（手势切片竞技场）

本地启动：`npm install`，然后 `npm run dev -- --host 127.0.0.1 --port 5183 --strictPort`。
入口：http://127.0.0.1:5183/fruit.html

选择「经典护盾」或「60 秒街机」，再选择摄像头或鼠标。开启摄像头后，手掌朝向镜头，伸直食指，试挥一次即可完成校准并开始游戏。弯曲食指或握拳收刀。
坐姿下将手保持在画面中间区域，指尖通过收窄后的 `GESTURE_REGION` 映射到游戏区域，左右移动幅度约为完整画面的 48%。右下角可以显示摄像头骨架预览和手势控制区。
鼠标/触屏模式按住划动；键盘方向键移动、空格切割。停止摄像头或切换到鼠标会释放摄像头。视频仅在本机处理。
舞台在宽屏下限制为约 940px；游戏中始终显示“手势控制 / 鼠标控制”切换，摄像头失败或玩家手臂疲劳时可立即继续用鼠标。

水果被切开后会按刀锋角度分裂成两半，并产生果汁粒子、切面高光、文字反馈、短顿帧和轻度屏幕震动。
经典护盾模式命中炸弹扣 1 个护盾，3 个护盾耗尽后结算。街机模式普通水果 10 分，炸弹扣 30 分且最低为 0，倒计时结束后结算。两种玩法分别保存本机最高分。街机模式中，单刀切中第 3 个及后续水果各加 5 分，还有暴击、40 分金果与持续 5 秒的冰冻果。
声音由 Web Audio 实时合成，切割音带随机音高与滤波变化，炸弹使用低频冲击和噪声爆炸，不依赖外部音频文件。
声音和动效可在游戏内分别关闭。关闭动效会减少粒子，并关闭震动、顿帧和动态背景光。点击「暂停」或按 Esc 暂停，切换标签页会自动暂停，暂停期间不会累计游戏时间。

连续切割会积累“流光能量”。蓄满 100% 后自动进入 7 秒流光时刻：每次切片双倍计分，
舞台进入持续暖色高能状态，水果出现脉冲能量环，刀光切换为青金轨迹；炸弹会直接清空能量。
游戏已取消全屏闪光反馈。
手机或 760px 以下的窄屏设备首次打开时自动进入触屏模式，顶部可随时切换到摄像头手势模式。

GitHub Pages 由仓库根目录的 `.github/workflows/deploy-slice-arena.yml` 构建并发布本目录的 `dist`。
部署地址为 `https://cnlpf.github.io/AI_Child_learninig/fruit.html`。

美术方向为原创“黄昏果园竞技场”：暖金、珊瑚、奶油白与深墨绿配色。苹果使用双瓣轮廓和果核，
橙子、青柠使用径向果瓣，西瓜使用条纹表皮、红瓤和籽粒；炸弹有金属球体、引线和动态火花。
普通命中有方向性刀光、52ms 顿帧、命中缩放和连击文字；炸弹拥有 125ms 强顿帧与更大的镜头冲量。

fruit.html / src/fruit/main.ts / style.css 是独立入口与界面；audio.ts 是程序化音效；rules.ts 是线段和圆碰撞判定。
鼠标、触屏和键盘的切割门槛为 90 CSS 像素/秒。手势门槛按画布宽度调整，最小为 125 CSS 像素/秒。间隔达到 120 毫秒或手势出现明显跳点时会断开轨迹。碰撞宽容度为水果半径 + 8，指尖弯曲阈值为 0.55。
`?bot=1` 使用合成手势通过真实手势引擎试玩。`window.__fruit` 暴露 hands、score、lives、fruits、slice、begin、spawnBomb 测试钩子。

基线保存在本地分支 `codex/fruit-storm-baseline`（`4273fc1`）。本轮复用 Canvas 2D、MediaPipe 1.1.0 与 Vite 8.3.4。本轮 64 项单元测试和生产构建通过。Edge 生产预览验证了鼠标挥切、模拟触屏拖动、三果连切、炸弹规则和五局加速结算。软件视频流用于验证 MediaPipe 初始化、校准状态、权限拒绝、断开回退和轨道释放。合成手势试玩在 Edge 无头模式、1280×820、DPR 1 下测得帧间隔 p50 约 16.7 ms、p95 约 16.9 ms。真实摄像头、实际手机浏览器和线上托管路径需单独实测。
