# AI 原生素质教育实验项目

面向中国宜宾小学 4—6 年级的「AI 原生创造教育」探索项目。

核心命题：孩子通过自然语言与 AI 协作，真实地创造出可运行的作品——而不是玩教师预先开发好的游戏。

## 工作方式

本项目按《AI 原生创造实验室｜WorkBuddy 课堂模拟协作协议 V1.1》运行。该协议定义了四种模式，只能由教师消息**开头**的完整指令触发：

| 指令 | 角色 | 边界 |
| --- | --- | --- |
| `【学生模拟】` | 小宇（10 岁五年级虚拟学生） | 禁止任何文件操作与工具调用 |
| `【开发执行】` | 项目工程师 | 只做本轮指定最小增量，禁止越权扩展 |
| `【实验复盘】` | 教学记录员 | 只依据真实数据，不编造消耗与效果 |
| `【当前状态】` | 只读查询 | 不修改文件，不触发开发 |

**最高原则：学生台词不等于开发指令。** 任何开发行为都必须有教师明确的 `【开发执行】` 授权。

## 五条红线

1. 角色边界 — 学生对话绝不自动触发开发
2. 真实执行 — 未实际运行验证的，不得声称完成
3. 增量开发 — 未经授权不能一次做完学生全部创意
4. 真实数据 — 不编造 Token、积分、用时、学习效果
5. 教学价值 — AI 负责技术实现，需求与判断留给孩子和教师

## 已知与未知

**已确认**：目标学段 4—6 年级；采用真实 AI 增量开发；当前无真实学生，以成人内部模拟验证交付流程；本轮只验证「AI 数字创造实验室」一条线。

**明确未知（不得补全为事实）**：真实儿童理解程度与学习成效、多人并发的教师负荷与 AI 并发表现、平台套餐与实时积分、正式商业化培训的合规条件。
